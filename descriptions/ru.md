# Программа восстановления Linux Fresh Install

Программа предназначена для **восстановления Linux до состояния, максимально близкого к чистой установке**, без переустановки всей операционной системы.

Главная цель — удалить установленные пользователем приложения, дополнительные пакеты и их конфигурацию, вернув систему к исходному состоянию и сохранив стандартные компоненты дистрибутива и официальные обновления.

## Принцип работы

Программа анализирует текущее состояние системы и определяет пакеты и приложения, относящиеся к:

- исходной установке дистрибутива;
- официальным обновлениям системы;
- приложениям, дополнительно установленным пользователем;
- дополнительным зависимостям и ненужным пакетам.

При восстановлении добавленные пользователем приложения удаляются, а в системе остаются **приложения дистрибутива по умолчанию и их официальные обновления**.

## К чему стремится программа

После восстановления система должна выглядеть так, словно была выполнена чистая установка Linux и установлены все официальные обновления, выпущенные к моменту восстановления.

Программа не должна возвращать старые версии пакетов. Её цель — восстановить **чистый состав системного программного обеспечения**, а не обязательно прежние версии пакетов.

## Основные функции

- Автоматическая инвентаризация установленных пакетов.
- Отделение системных пакетов от установленных пользователем.
- Удаление приложений, добавленных пользователем.
- Очистка ненужных зависимостей и оставшихся пакетов.
- Исправление состояния пакетного менеджера.
- Сохранение официальных обновлений дистрибутива.
- Возможность сохранения системной конфигурации и пользовательских данных.
- Режим dry run для просмотра удаляемых пакетов до восстановления.
- Журнал восстановления с записью всех выполненных действий.

## Безопасность

Поскольку программа изменяет состояние системных пакетов, перед восстановлением рекомендуется создать резервную копию важных данных.

Программа не должна автоматически удалять пакеты, необходимые для загрузки и основных функций системы. Перед применением изменений пользователю должна предоставляться понятная сводка удаляемых пакетов и приложений.

## Результат

**Fresh Install Restore** позволяет стремиться к чистому, стандартному составу программного обеспечения Linux:

> **Приложения дистрибутива по умолчанию + официальные обновления системы − приложения, добавленные пользователем.**

Так можно очистить систему и вернуться к чистой программной среде без переустановки всей операционной системы.
