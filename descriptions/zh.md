# Linux Fresh Install 系统还原程序

本程序旨在**将 Linux 发行版还原到尽可能接近全新安装的状态**，而无需重新安装整个操作系统。

主要目标是删除用户安装的应用程序、额外的软件包及其配置，使系统回到初始状态，只保留标准发行版安装所包含的软件和官方系统更新。

## 工作原理

程序分析当前系统状态，识别属于以下类别的软件包和应用程序：

- 发行版的初始安装；
- 官方系统更新；
- 用户后来安装的应用程序；
- 额外的依赖项和不再需要的软件包。

还原时删除用户后来添加的应用程序，保留**发行版默认应用程序及其官方更新**。

## 目标

还原后的系统应当类似于刚完成 Linux 全新安装，并安装了截至还原时发布的所有官方系统更新。

程序不应降级软件包。其目标是还原**干净的系统软件组成**，而不一定是还原旧的软件包版本。

## 主要功能

- 自动清点已安装的软件包。
- 区分系统软件包和用户安装的软件包。
- 删除用户后来安装的应用程序。
- 清理不需要的依赖项和残留的软件包。
- 修复软件包管理器状态。
- 保留发行版官方更新。
- 提供保留系统配置和用户数据的选项。
- 提供 dry run 预演模式，在还原前查看将要删除的内容。
- 记录所有操作的还原日志。

## 安全

由于程序会更改系统软件包状态，建议在还原前备份重要数据。

程序不应自动删除启动系统或维持基本功能所必需的软件包。在应用更改前，必须清楚地向用户展示将被删除的软件包和应用程序摘要。

## 最终结果

**Fresh Install Restore** 旨在让 Linux 恢复干净、标准的软件状态：

> **发行版默认应用程序 + 官方系统更新 − 用户后来安装的应用程序。**

这样可以在不重新安装整个操作系统的情况下清理系统，回到干净的软件环境。
